# Исправления (ревью кода)

Проверено статически: компиляция всех .py, `bash -n install.sh`, поиск битых импортов и
неопределённых имён, тест парсера сумм. **Приложение целиком не запускалось** (в среде нет
fastapi/SQLAlchemy/PostgreSQL) — перед выкаткой прогоните на стенде.

## Критичные
- `api/v1/services.py`: импорт несуществующего `current_user` → приложение падало при старте.
- `ui/admin.py`: `approve/reject` вызывали async `_process` без `await` → заявки на пополнение
  не зачислялись никогда.
- `api/internal/debug.py`: эндпоинт без авторизации отдавал балансы и сессии всех клиентов.
- `services/usage.py`: логи с неопределёнными переменными (`session`, `ticks`, `product`) →
  `UnboundLocalError`/`NameError` на каждом тике, когда нет сессий, и всегда в `close_stale_sessions`.
- `install.sh`: `[ -n "$GIT_TOKEN" ] && chmod …` в конце функции + `set -e` → установка
  публичного репо обрывалась после `git clone`.
- `docker-compose.yml`: порт API 8008 был открыт на все интерфейсы в обход Caddy.

## Деньги / ledger
- `ledger.post_entry`: сначала блокировка кошелька (`populate_existing`), потом проверка ключа
  идемпотентности; ключ, уже использованный для другого кошелька/суммы, → `IdempotencyConflict` (HTTP 409)
  вместо молчаливого «успеха». Нулевые проводки запрещены.
- Один активный `UsageSession` на аккаунт (частичный уникальный индекс + обработка гонки) — защита
  от двойного списания. `init_db.py` закрывает уже существующие дубли и создаёт индекс.
- Списание: каждая сессия в своей транзакции, `FOR UPDATE SKIP LOCKED`, закрытие сессий неактивных услуг.
- Пополнение в ЛК: `float` заменён на `Decimal` (по принципам README), `inf/nan/1e400` больше не дают 500, лимит суммы.
- `sync.py`: срок для 3x-ui считался в минутах независимо от единицы тарифа; выключенные клиенты
  перепушивались каждые ~2 минуты.

## Provisioning
- Задачи: ошибка хэндлера теперь откатывает транзакцию (раньше → `PendingRollbackError`/частичные изменения),
  до 3 попыток, возврат зависших `running`, `SKIP LOCKED`, неизвестный `entity_type` больше не оставляет задачу в `running`.
- `enqueue_task`: ключ с timestamp не давал идемпотентности — теперь дедупликация по (сущность, действие, pending/running).
- `create` идемпотентен (аккаунт уже есть → пропуск); при удалении освобождается IP.
- `ipam`: блокировка ноды, нормализация INET, `.1` зарезервирован под сервер WireGuard.

## 3x-ui / WireGuard
- Кэш `httpx.AsyncClient` и `asyncio.Lock` между вызовами `asyncio.run()` ломался ("Event loop is closed") —
  теперь кэшируются только cookie+CSRF.
- Панель отвечает HTTP 200 с `success:false` — раньше ошибки молча считались успехом.
- Чтение-изменение-запись inbound сериализовано (потоки воркера затирали друг друга).
- SSH: ключ из памяти (без temp-файла), `shlex.quote`, таймауты, опциональная проверка `ssh_known_hosts`
  в `node.extra` (без неё MITM по-прежнему возможен — предупреждение в логе).

## Безопасность / прочее
- Админка: пересверка роли в БД при каждом запросе, кошелёк не редактируется руками (только ledger),
  `password_hash` скрыт, секреты нод шифруются при сохранении, удаление пользователей/кошельков/нод отключено.
- ЛК: заблокированный пользователь теряет сессию, suspend/resume только из допустимых статусов,
  нормализация email (регистр), обработка гонки при регистрации.
- CCTV: дедупликация заказа по `idempotency_key`, 409 при конфликте ключей, валидация `months/price_minor`.
- Админ-API: `Literal`-валидация типов/единиц/протоколов, 409 вместо 500 при дублях.
- Worker: логирование (раньше `log.info` не выводился), `coalesce/max_instances`.
- Прочее: дубли импортов/роутеров в `main.py`, `install.sh` (бэкап через общий код, ротация 14 дней, `zstd`,
  таймаут ожидания БД, пароль админа без спецсимволов, токен не остаётся в `.git/config`).

## Не менял, но стоит учесть
- Версии зависимостей в `requirements.txt` не зафиксированы.
- `verify_tls` для 3x-ui по умолчанию `False`.
- Redis подключён в compose, но в коде не используется.
- Нет миграций (только `create_all`); нет защиты от brute-force на логине и CSRF-токенов в формах ЛК
  (частично смягчено `SameSite=lax`).
- Тариф «поминутно» списывает только полные минуты — неполная последняя минута сессии бесплатна.
