Как это работает

  • Импорт ноды: вставь JSON входящего подключения 3x-ui → укажи код/страну → «Импортировать». Биллинг сам создаст inbound в панели (если id не указан) и пропишет ноду с ключами.
  • Быстрые тарифы: четыре цены (копейки) → «Создать/обновить». Тарифы сразу появляются в кабинете клиента.
  • База знаний: рецепты тарифов, жизненный цикл услуг, деньги, troubleshooting.
