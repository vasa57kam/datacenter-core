Как это работает

  • Импорт ноды: вставь JSON inbound из 3x-ui. Inbound ID = 0 → inbound создастся в панели сам; иначе привязка к существующему id. Для ноды с другого сервера заполни блок «Внешняя панель» (URL + логин/пароль или API-токен).
  • Тарифы: 4 цены в копейках (сек/мин/ГиБ/мес) → создаётся или обновляется набор vpn-<proto>-second|minute|gb|month. Месяц списывается один раз при активации; сек/мин/ГиБ — по факту использования.
  • Пароли: смена своего пароля с проверкой текущего; установка пароля любому пользователю из списка.
