📒 Инструкция кассира

  1. Кассир работает только в кассе (/lk/kassa): приём наличных и заявки на наличные.
  2. Клиент не видит способ «Наличные» — наличные принимает только касса/админ.
  3. Принял деньги → выбрал клиента из списка (или email вручную) → «Принять и зачислить» → баланс растёт сразу.
  4. Ошибка суммы → сообщите админу: правка баланса только у админа, всё пишется в «Аудит».
  5. Полная версия для клиента-кассира: /lk/kassa/guide.
