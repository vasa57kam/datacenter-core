# Партнёрский договор о доле в доходе (ШАБЛОН — адаптировать с юристом)
ВАЖНО: публичное привлечение денег граждан под доход без правового оформления = риски (ст. 14.1 КоАП, 259-ФЗ об инвестплатформах, признаки НБО). Рабочие формы: (а) ИП/ООО + договор простого товарищества/оказания инвест-услуг с распределением прибыли; (б) займ с процентом, привязанным к выручке; (в) доля в ООО через уставный капитал. Публично слово «дивиденды» использовать только для ООО-участников; для физлиц-партнёров — «партнёрское вознаграждение из прибыли».
1. Предмет: партнёр передаёт платформе средства/оборудование; платформа ежемесячно/ежедневно начисляет долю прибыли пула (процент пула фиксируется офертой-приложением).
2. Формула: пул = N% выручки услуг за период; доля партнёра = его % пула; начисление автоматизировано, журнал начислений = приложение к отчёту.
3. Выплаты: по заявке партнёра на реквизиты, срок 1 рабочий день; налоги: для физлиц платформа-ООО выступает налоговым агентом (НДФЛ), для ИП/ООО — самостоятельно.
4. Риски: доход не гарантирован; убыточный период = нулевой пул; досрочный выход — возврат вложенного по остаточной стоимости оборудования/согласованной формуле.
5. Отчётность: партнёр видит выручку и начисления в личном кабинете (прозрачность снижает споры).
6. Прекращение: блокировка за нарушение оферты пользователем-партнёром не лишает начисленного.
