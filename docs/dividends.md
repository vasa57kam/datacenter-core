# Как рассчитываются дивиденды ITKAM34
## Формула (одна строка)
- Выручка за день = сумма всех списаний за услуги (поминутно/посекундно/активации) за вчера.
- Пул = Выручка × Процент пула (настройка в пульте «Дивиденды», по умолчанию 30%, 0 = выключено).
- Начисление партнёра = Пул × (доля партнёра / сумма долей всех активных партнёров).
- Начисление происходит автоматически каждую ночь в 00:05 на баланс партнёра в кабинете.
## Примеры
- Выручка 333 ₽, пул 30% = 100 ₽; один партнёр с долей 100% получает 100 ₽.
- Выручка 10 000 ₽, пул 30% = 3 000 ₽; доли 70/30 = 2 100 ₽ и 900 ₽.
- Выручка 0 ₽ (никто не пользовался) = пул 0 ₽, начислений нет. Доход НЕ гарантирован.
## Правила, чтобы не переплатить (памятка владельцу)
- Держи процент пула ≤ 30: это уже после всех расходов инфраструктуры.
- Сумма долей партнёров должна быть 100% (иначе система нормирует пропорционально, но порядок в таблице = прозрачность для инвесторов).
- Вывод денег возможен ТОЛЬКО заявкой с начисленного баланса: заявка больше баланса не пройдёт (защита от переплаты).
- Одна заявка = одно списание с баланса партнёра (идемпотентность): повторное одобрение невозможно.
- Внешнему инвестору без аккаунта начисления ведутся в таблице, но на баланс не падают: выплачивай вручную по договору и жми «Выплатил» (списание не производится — сверяйся с таблицей начислений).
- Отключай партнёра кнопкой «Выключить» при расторжении договора: начисления прекратятся со следующего дня, история сохранится.
- Налоги: для физлиц-партнёров платформа-ООО выступает налоговым агентом (НДФЛ с вознаграждения); для ИП/ООО-партнёров — они учитывают доход сами. Проконсультируйся с бухгалтером перед первыми выплатами.
- Юридическая форма привлечения: договор простого товарищества / партнёрский договор о доле прибыли (шаблон docs/legal/partner_dividends_template.md). Публично слово «дивиденды» используй только для участников ООО.
## Где смотреть
- Владелец: пульт → «Дивиденды» (формула с живыми цифрами, партнёры, начисления, заявки).
- Партнёр: кабинет → карточка «Вы партнёр платформы» → «Мои дивиденды и вывод».
- Инвестор без услуг: вход /invest → попадает в обычный кабинет с карточкой партнёра.
